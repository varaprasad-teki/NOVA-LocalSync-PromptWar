# NOVA CART — Flipkart-style Local Commerce UI

A competition prototype inspired by familiar Indian e-commerce interaction patterns, while keeping NOVA LocalSync's differentiated inventory-confidence workflow.

## Main flow
Home → Categories → Product discovery → Product card → Cart → Availability pre-check → Checkout intervention.

## Differentiator
The UI does not simply say "In Stock". It surfaces:
- High / Medium / Low availability confidence
- Store name
- Freshness of stock confirmation
- A pre-check before payment
- Substitute/confirmation intervention for low-confidence items

## Demo
Open `index.html`.

Try:
1. Search "notebook".
2. Add "A4 Notebook 200 pages".
3. Open the cart.
4. Notice the low-confidence warning.
5. Click PLACE ORDER to see the intervention.

## Competition positioning
Do not claim this is Flipkart or copy Flipkart branding/assets. Present it as a modern e-commerce UX inspired by familiar shopping patterns, with NOVA LocalSync's original business workflow.
